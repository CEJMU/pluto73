# Hardware measurement archive

Raw execution logs and spectrum captures from the on-device diagnostic suite, one directory per generating command. Every log opens with a `# command:` line recording the exact invocation that produced it, and the transmit spectral-purity modes additionally print a run-configuration block naming the operating point in full (LO, sample rate, TX DDS offset, RX gain, signal path, build).

Measured 2026-08-02 on a PlutoSDR (Zynq XC7Z010, AD9363) over the standard bench rig:
TX1 -> 20 dB attenuator -> RX1 coaxial cable. Runs tagged `_bist` instead use the AD9361 built-in digital loopback, which routes the transmit data back inside the transceiver with the DAC, mixer, PA, ADC and both local oscillators bypassed; comparing the two isolates the digital pipeline (software modulator + FPGA) from the analog front end.

## Transmit chain

| Directory                              | Command                                       | What it establishes                                                                                                                                                                                                                                                                                                                                                               |
| -------------------------------------- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `test-spec-tx-radiated/`               | `--test-spec-tx-radiated`                     | **Primary TX evidence.** Real modulator + FPGA TX pipe, read back through the stock wideband ADC path, so no custom receive DSP grades the transmitter. Carrier and sideband suppression, two-tone IMD3/IMD5, quadrature image, and a wideband spur scan with radiated-vs-receiver attribution.                                                                                   |
| `test-spec-tx-radiated/repeatability/` | `--test-spec-tx-radiated` x5, `--loopback` x5 | Ten independent invocations, each re-tuning and re-calibrating the transceiver                                                                                                                                                                                                                                                                                                    |
| `test-dma-carrier-offset/`             | `--test-dma-carrier-offset`                   | Independent corroboration of the in-channel figures via the FPGA audio DMA path. Shares no DSP with the raw path above; the two agree within a few dB.                                                                                                                                                                                                                            |
| `test-spec-tx-wideband/`               | `--test-spec-tx-wideband`                     | Burst wideband spectrum and spur scan against a TX-off baseline.                                                                                                                                                                                                                                                                                                                  |
| `test-spec-tx-twotone/`                | `--test-spec-tx-twotone`                      | Two-tone linearity via the burst wideband path.                                                                                                                                                                                                                                                                                                                                   |
| `test-spec-tx-shape/`                  | `--test-spec-tx-shape`                        | Transmit passband shape across the audio band.                                                                                                                                                                                                                                                                                                                                    |
| `test-spur-probe/`                     | `--test-spur-probe`                           | Fabric sample-pacing sidebands in eleven configurations, read at +-9.6 and +-19.2 kHz from the transmitted line and reported in-process. Constant feed through the digital loopback reaches the -141 dBc numerical floor; disabling the fabric DSP raises the same sidebands to -27 dBc, which is what the strobe is worth. Raw IQ blocks are also dumped for deeper offline work |

## Receive chain and real-time behaviour

| Directory                    | Command                       | What it establishes                                                                                              |
